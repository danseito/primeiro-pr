# Primeiro PR

Este repositório foi criado para praticar o fluxo de contribuição com Pull Requests.

## Como contribuir

1. Faça um fork do repositório
2. Crie uma branch: `git checkout -b minha-melhoria`
3. Faça suas alterações e commite: `git commit -m "descrição da melhoria"`
4. Envie para o GitHub: `git push origin minha-melhoria`
5. Abra um Pull Request

## Funcionalidades

- Exemplo de projeto simples
- Estrutura básica de repositório
- Bom ponto de partida para aprender Git e GitHub
